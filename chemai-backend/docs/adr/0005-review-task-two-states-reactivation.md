# 复习任务两态模型 + 已掌握后重新激活

`ReviewTask` 只落库 `pending` / `done` 两态，「超期（overdue）」是查询时 `next_review_at <= now` 的派生标签，不落库、无定时任务翻转状态。学生「标记已掌握」或复习达 5 级进入 `done` 后，若**再次答错同一题**，同步逻辑将任务重置为 `level=0、status=pending` 重新进入螺旋，而非永久豁免——「已掌握」是当时判断，之后答错是遗忘/未真掌握的硬信号，永久豁免会违背「答错自动同步」的闭环。去重键 `(student_id, question_id)` 不变，仅重置状态。

## Consequences

- 状态翻转路径单一，无「已到期但状态仍 pending」的不一致。
- 后续接家长通知/学情预警时，若需「超期时长」细分，再引入额外状态或提醒维度。
