# OCR 判卷 v1 判分引擎纯确定性，主观题/LLM 判分后置

OCR 判卷 v1 的判分引擎采用**纯确定性**实现——仅覆盖客观题（选择题）与填空题，判分方式为「化学式/数字/空白规范化后与参考答案比对」，不引入 LLM 语义判分；主观题（计算/实验/推断）与设计文档中的 `correct_edu` / LLM 判分两条路径均后置。选择确定性而非 LLM，是因为化学主观题（方程式配平、计算过程）的 LLM 判分幻觉风险高、结果不可验证，需「待复核 + 教师确认」兜底抵消自动化收益；而客观/填空确定性判分置信度高、可单元测试，符合「简单优先」——先跑通「OCR → 判分 → 入库 → 诊断」闭环，再叠加智能判分。

## Considered Options

- **LLM 语义判分（千问，设计文档路径）**：覆盖主观题，但幻觉风险高、判分结果不可验证，需教师逐题复核抵消自动化收益。
- **Baidu `correct_edu` 判卷 API**：依赖百度判卷能力，与自建题库/参考答案解耦，且对化学主观题无学科优势。
- **纯确定性判分（已采纳）**：客观+填空可靠可测，主观后置为独立迭代。

## Consequences

- 判分结果只有「正确 / 错误 / 待复核」三态，「待复核」触发 = OCR 无法可靠抽取作答（低置信度/空/无法解析），而非判分置信度。
- `llm_service` 无需新增 `grade_answer`；LLM 仅保留在诊断环节（复用 `diagnose_answers_background`）。
- 主观题判分作为后续独立 change，届时再评估 LLM/其他判分引擎。
